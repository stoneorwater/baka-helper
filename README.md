# Baka助手

学习通学习辅助 · AI 接口 · 本地正确答案题库

[安装脚本](https://raw.githubusercontent.com/stoneorwater/baka-helper/main/baka-helper.user.js) · [使用指南](docs/USAGE.md) · [版本发布](https://github.com/stoneorwater/baka-helper/releases) · [问题反馈](https://github.com/stoneorwater/baka-helper/issues)

**当前脚本版本：0.9**
</div>

Baka助手是运行在 Tampermonkey 中的浏览器用户脚本，将课程导航、视频与阅读辅助、可配置 AI 接口和答案题库集中在可拖动的琪露诺悬浮面板中。适配以桌面端学习通页面为主，网页改版和浏览器休眠可能影响运行。

## 功能

| 模块 | 能力 |
| --- | --- |
| 学习辅助 | 定位未完成内容、视频续播、章节衔接、可调阅读停留时间和滚动速度 |
| AI 设置 | OpenAI / ChatGPT API、DeepSeek、硅基流动、Gemini、Claude 与自定义兼容接口；手动模型 ID、模型列表、可选思考设置 |
| 答题辅助 | 文字或截图识题、填写前校验、多选复核、可选自动提交；不确定答案记录待处理 |
| 正确答案题库 | 收集明确公布的正确答案，或逐题判对的“我的答案”；搜索、统计、去重与冲突保留 |
| 独立顺序收集 | 从第一节依次浏览当前课程的测验；可停止、继续，不需要 API，不填写或提交题目 |
| 跨电脑复用 | 导出全部或勾选导出 JSON，导入合并；可选优先匹配题库，按选项内容处理字母换序 |
| 异常恢复 | 无进展超时重试、返回课程与跳过记录、页面运行权切换、可选登录辅助 |
| 界面 | 可拖动悬浮球、避让布局、毛玻璃背景、过渡动画、减少动态效果适配 |

## 安装

1. 在 Edge 或 Chrome 中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击 **[安装 Baka助手](https://raw.githubusercontent.com/stoneorwater/baka-helper/main/baka-helper.user.js)**，在扩展安装页确认。若只看到源代码，新建用户脚本，粘贴整个文件并保存。
3. 打开课程章节页面并刷新，点击琪露诺悬浮球展开面板。

**从旧版更新：** 建议在原脚本编辑器中替换全部代码，以保留设置。不要同时运行新旧两份脚本；内部存储命名保持兼容。图片已内置，无需另外安装素材。

## 快速使用

### 收集已有正确答案

打开 **题库 → 收集当前页**。如需持续收集，开启“自动收集正确答案”；如需单独遍历当前课程，点击 **从第一节收集**，之后可停止或继续。未作答、仅有得分、答错或未显示答案的题目不会被当成正确答案。

### 在另一台电脑使用题库

点击“导出全部”，或勾选条目后“导出所选”。把 JSON 文件传到另一台电脑，在同版助手中“导入题库”，再按需开启“优先使用题库答案”。导入会去重，冲突答案不自动套用。系统支持文件分享时可直接打开分享菜单，否则下载文件。

### 使用 AI

在 **AI 设置**选择服务商，填写自己的 API Key，选择或填写模型 ID 后保存。“检测连接 / 读取模型”验证密钥与模型列表，“测试回答”会发起实际请求。图片题需要对应接口和模型支持图片输入；模型名称和可用能力以服务商为准。

按需开启“AI 填写习题”及“自动提交习题”。全自动开始会同时启用视频、习题与提交，请先确认面板选项。不确定答案不会被当成平台正确答案存入题库。AI 输出仍可能错误。

更完整的配置、独立收集、异常恢复与登录辅助说明见 **[使用指南](docs/USAGE.md)**。

## 数据与权限

- AI 密钥、设置和题库保存在本机用户脚本管理器中；调用 AI 时会把题目文字或截图发送给你配置的服务商，可能产生费用。
- 题库导出仅包含题目、选项、答案、课程编号与题号，不包含账号密码、API Key、Cookie 或页面地址；不会自动上传题库。
- 可选“保存账号密码”采用本机**未加密存储**，默认关闭，可随时删除；仅用于保存时的登录站点。
- 人机验证需要手动完成。本项目不提供自动绕过验证码的功能。
- 安装权限包含学习通相关页面与自定义 AI 地址请求；详细说明见 [隐私与权限](docs/PRIVACY.md)。

## 已知限制

网页布局、加密字体、嵌套框架和浏览器节能策略可能影响识别或续播。图片不随题库导出，含图片的题目不只凭文字自动复用。独立收集只遍历当前目录中的测验，不打开历次作答菜单。未进行所有课程布局的完整实测，也不承诺答案准确率或始终不停机。

请在你有权使用的课程中，按所在学校和平台要求使用。本项目与超星、学习通及各 AI 服务商无隶属关系。

## 开发

需要 Node.js 22 或更新版本。

```sh
npm ci
npm test
npm run build
```

源码位于 `src/`；构建会把插画嵌入根目录的 `baka-helper.user.js`。测试使用虚构题目，不连接真实课程、不调用真实 AI、不提交作业。提交修改时请同时更新构建后的脚本。
