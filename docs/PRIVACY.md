# 隐私与权限

Baka助手无需注册额外账号，也不内置项目运营方的收集服务器。题库和设置保存在用户脚本管理器的本机存储中。

| 数据 | 存储或发送位置 |
| --- | --- |
| API Key | 本机存储；作为请求认证信息发送给所配置的 API 地址 |
| 题目文字或截图 | 启用 AI 时发送给所配置的服务商 |
| 题库 | 本机存储；只有主动导出或分享才生成共享文件 |
| 登录账号密码 | 只有明确点击保存才写入本机，未加密；只填写到保存时的 HTTPS 登录站点 |

脚本使用 GM_getValue / GM_setValue 存储设置和题库，GM_getTab / GM_saveTab 管理标签页运行权，GM_openInTab 打开阅读页，GM_xmlhttpRequest 请求模型。unsafeWindow 用于访问学习页面；部分页面可见性事件会在运行时受脚本影响。@connect * 用于允许自定义 AI 接口地址，并不意味着向所有站点发送数据。

html2canvas 1.4.1 通过 jsDelivr 的 @require 加载，用于生成题目截图。背景图片内嵌于脚本。安装来源、更新地址和完整权限请查看脚本头部。

题库文件不带密钥、登录信息和页面地址，但包含题目内容、课程编号与题号。共享前请自行检查文件。卸载前可导出题库；删除浏览器或扩展数据可能丢失本机设置。
