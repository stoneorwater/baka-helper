# Baka助手 · 0.9

## 更新方法

在 Tampermonkey 中打开原助手的编辑页，用 baka-helper.user.js 全部内容替换，保存后刷新课程页。名称和版本应显示 Baka助手 0.9。请在原脚本中替换，不要同时开启新旧两份脚本；内部存储名称保持兼容，以沿用原有设置、密钥和位置。

图片和图标已内置在脚本中，不需要额外安装素材或开启本地服务。

## 本次修复：判对结果与独立顺序收集

部分结果页只显示“我的答案”和逐题绿色对勾，不显示“正确答案”文字。现在支持同一道题内的明确判对标记；判断题结果省略选项时补充“对 / 错”映射。错题、部分正确、隐藏标记和仅有得分的结果不会作为正确答案入库。

在“题库”标签点击“从第一节收集”，即可独立遍历当前课程目录，逐节打开章节测验，收集已有正确答案。该模式不需要 API Key，也不需要开启“自动收集正确答案”或全自动学习，不执行视频播放、AI 答题、填写或提交操作；启动时暂停原学习流程。

支持“停止收集”和“继续收集”。进度保存在当前浏览器标签页对应的本机记录中；刷新或返回后保持停止，点击继续可接续。不会跳过已完成章节，题库重复记录会自动去重。加载超时、未作答、未公布答案或未判对的内容会计入跳过；登录、验证、运行权转移及手动切换章节会停止，处理后可继续。只遍历当前课程目录中的测验卡片，不切换其他课程，也不自动打开历次作答下拉菜单。

## 正确答案题库

在悬浮窗的“题库”标签中使用，名称与版本继续保持 Baka助手 0.9。

- “自动收集正确答案”默认关闭。开启后收集结果页明确显示的“正确答案 / 参考答案”，或同题明确判对的“我的答案”，包括手动提交后的结果。不会将 AI 推测、已勾选的选项、得分或“已完成”状态当作正确答案。自动跳转前额外等待约 3 秒收集延迟加载的结果。
- “收集当前页”可手动执行，不必开启自动收集。网站未公布答案、未识别到结果格式或答案仍在加载时，不会新增记录；可稍后再次手动收集。
- 显示题目数、答案条数、导入条数、冲突数及已选数量。支持搜索题干、题号或课程编号，每页展示 30 条。
- “导出全部”导出 JSON 文件；勾选题目后可“导出所选”。“分享题库文件”在系统支持时打开分享菜单，否则下载文件，之后可通过聊天软件、网盘或 U 盘自行传给其他电脑。未勾选时分享全部，有勾选时只分享所选。
- 另一台电脑安装同版助手后，点击“导入题库”选择 JSON 文件。导入合并且去重，不覆盖原有记录；同题不同答案保留为冲突，不自动套用。单次导入最多 10 MB / 10000 条。
- 如需复用，开启“优先使用题库答案”。命中题干、题型及完整选项内容后，在 AI 请求前使用题库，并按内容重新匹配选项字母。未命中或冲突时走原 AI 流程；未配置 AI 则仍需配置或手动处理未命中的题目。导入答案不会被标成当前设备已核验答案。
- 支持文字选择题、判断题，以及可解析的文字参考答案。填空答案支持分号分隔格式。图片不打包；含图片的题目不自动复用。网页加密字体题仅在同课程、同题号及提取内容一致时匹配，跨电脑可能无法命中，不保证乱码题干可读。
- 共享文件只含题干、题型、选项、正确答案、课程编号和题号，不导出 API 密钥、登录账号密码、Cookie 或页面地址。题库默认只保存在本机，不自动上传。

## 已有修复：页面占用与重新登录

- 离开、刷新或返回课程时释放当前页面的运行占用；返回缓存中的页面会重新申请运行权，旧页面不能续期或清除新页面的占用。
- 其他页面确实在运行时仍保持单页运行。需要切换时，点击“在本页继续（停止其他页）”；失效占用最迟在 90 秒后可以重试。
- 在登录页新增账号密码保存和自动尝试登录。已按指针平台 v8.chaoxing.com 的登录表单适配，并支持 passport2.chaoxing.com 上能识别到的标准账号密码表单。
- 首次使用：在网页原有登录框填写账号密码，在 Baka助手中勾选“自动尝试登录”，再点击“保存本页账号密码”。保存默认关闭；开启后每次恢复流程自动尝试一次，避免连续重复登录。检查失败原因后可点“尝试登录一次”。
- 账号密码存于本机 Tampermonkey 存储，未加密；只填入保存时的 HTTPS 登录站点，不发送给 AI。可点击“删除保存的账号密码”。修改密码后须重新保存。
- 登录失效前记录原章节。能识别登录入口时进入登录页，登录完成且识别到成功页面后返回原章节；没有匹配的入口或成功页面时，需要自行回到课程。
- 滑块、验证码和登录条款需手动完成；脚本等待验证，不模拟或绕过验证。密码错误、账号变更或频率限制时停止自动尝试。
- 人工暂停会取消当前章节恢复。页面上“取消章节恢复”也可以取消返回。提交过程中遇到登录失效，恢复后先核对提交结果。

## 界面

- 名称统一为 Baka助手，版本统一为 0.9。
- 琪露诺人物近景插画作为背景，雾之湖仅保留局部；圆形头像使用同一人物插画，配有冰晶细节。
- 毛玻璃控制区保留文字对比度，人物脸部在顶部展示区清晰呈现。
- 展开和收起加入缩放淡入淡出，标签切换及按钮加入过渡；系统开启减少动态效果时自动停用动画。
- 悬浮球始终位于面板上层。优先向左右展开，空间不足则上下展开并调整面板高度；短窗口中面板可以整体滚动。
- 拖动超过阈值才移动，松手不会误触开关。支持页面范围内拖动跟踪，防止拖动时选中文字，记住最终位置。
- 点击球展开或收起，点击外部或 Esc 收起。连续快速开关不会被上次动画错误隐藏。

## 学习功能

保留全自动视频、阅读、AI 填写及可选自动提交，未完成任务定位，手动补题后接续，卡住刷新后重试、仍失败则跳过，以及移除累计 100 次请求限制等功能。

全自动运行按同一门课程的章节顺序推进，不切换其他课程。正常播放、阅读滚动和等待中的 AI 请求不作为无进展处理。手动暂停、登录验证、课程末尾或无法导航时仍可能停止。

学习面板可设置每页停留时间（默认 15 秒）、滚动速度（默认 80 像素/秒）、无进展等待（默认 300 秒）。先滚动到页尾，达到停留时长后自动翻页。

AI 设置、密钥和请求方式保持原有配置。重新填写本页会替换尚未提交页面的答案，完成后等待核对；不确定或暂不支持的题目保留在待处理列表。取消 100 次限制不会取消服务商额度或限流。
